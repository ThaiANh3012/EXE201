# Từ Vựng Có Ảnh (React)

Web React tối giản: chỉ giữ phần từ vựng và ảnh hiển thị trực tiếp trên màn hình.

## Chạy local

```bash
npm install
npm run dev
```

Mở `http://localhost:5173/`.

## Cách dùng

- Mở trang `/`.
- Danh sách từ vựng sẽ hiển thị ngay cùng ảnh nếu mục đó có ảnh trong workspace.
- Mục chưa có ảnh sẽ dùng emoji làm hình thay thế.

## Dữ liệu từ vựng

Danh sách từ nằm ở [src/data/vocab.ts](src/data/vocab.ts). Bạn có thể thêm/sửa từ ở đây.
